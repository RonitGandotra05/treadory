Treadory privacy

Treadory has no account, analytics, advertising, server or telemetry. Settings, device identity, learned USB patterns and optional website-origin presets stay in the extension’s local browser storage. Recent pedal presses remain in memory and are lost when the extension worker stops. Optional diagnostics keep up to 50 press outcomes in memory, including timestamps, action types and failure categories. Copy diagnostics creates a report only on request; it excludes website URLs, page content, device names, custom text, selectors and shortcut keys. Reports are not uploaded automatically; sharing a copied report is your choice.

USB access requires the browser’s device chooser. Website access is optional: choose one website or normal HTTP/HTTPS websites. The extension examines the active tab and the DOM only to perform your configured action. It does not collect browsing history or passwords and makes no background network requests.

Custom selectors, text and website shortcuts are local settings. Exported JSON includes these settings; share it only if you intend to disclose them. Removing website access or uninstalling the extension removes its ability to act on sites. Uninstalling removes local settings.

An explicit click on the source/setup link opens GitHub normally. No data is sent to GitHub automatically.
