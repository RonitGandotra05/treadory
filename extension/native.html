Windows helper download & setup ↗

Install the helper, then connect it here.

1. Inspect your pedal

Only a unique VEC 05f3:00ff mouse endpoint is eligible. Nothing is captured during inspection.

2. Start an isolated test

During capture, all original outputs from this pedal are suppressed. Your ordinary mouse remains active. Learning physical controls does not run configured actions.

3. Learn & choose

Learn each physical pedal individually: press, hold, then release. The middle pedal’s reported mouse button is learned, not assumed.

4. Verify across your computer

While the isolated test is active, press every pedal in another app: its unwanted outputs must be absent. Right-click with your ordinary mouse while pressing the middle pedal and check the mouse still works.

Tap actions work in normal desktop apps, including the browser. Elevated apps, UAC and secure desktops are excluded. Browser page mappings do not also run in this mode.

Recovery & privacy +

Ctrl + Alt + Shift + F12 stops capture on the normal desktop. Stop and Disconnect above also restore original input. Closing the browser/helper, a five-second heartbeat loss, device changes or desktop changes stop capture. Closing only this setup tab leaves the connection running.

Pausing chosen actions keeps the pedal’s original outputs suppressed. Stopping capture restores those original outputs. No capture starts automatically. Device ambiguity or unsupported input stops the session and requires learning again.

No network service or telemetry. Only the selected pedal is remapped; no ordinary mouse/key content is recorded. Settings remain in this browser. Remove the helper using its uninstall script; its separately installed driver has its own uninstaller.
